# CBMM 

soy preparador fisico de un club de rugby, CLUB BIBLIOTECA MARIANO MORENO (CBMM ).

Necesito crear una plataforma que, pueda recolectar datos utiles de los jugadores del plantel, datos subjetivos de ellos, con antelacion al entrenamiento, en donde me comentes a traves de un cuestionario de wellness como se encuentran y posterior al entrenamiento como finalizaron el mismo, dolores musculares cansancio muscular, entre otros. Quiero que todo estos datos se encuentren dentro de la plataforma de manera automatica, donde pueda visualizarlo de manera dinamica y grafica los resultados. Tiene que tenes el espacio para brindarle los datos al entrenador tanto general como individual de un jugador que el seleccione, con mapa de dolor muscular grafico con una persona especificando la zona, graficos que se pueda visualizar los datos recaudados. ayudame a crearlo para un mejor control de cargas en los entrenamientos
